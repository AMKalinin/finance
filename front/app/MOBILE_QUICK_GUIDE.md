# 📱 Мобильная Адаптация - Быстрый Гайд

## 🔥 Что изменилось?

### ✅ Новые возможности:

1. **Нижняя панель навигации** (mobile-only)
   ```
   [🏠]  [💳]  [📊]  [💸]  [👤]
   ```
   - Доступна на экранах < 1024px
   - Плавные переходы между вкладками

2. **Мобильное боковое меню** (slide-out)
   - Кнопка "гамбургер" в левом верхнем углу
   - Выезжает слева, оверлей затемняет фон

3. **Тёмная тема** 🌙
   - Автоматическое переключение по системным настройкам
   - Все компоненты поддерживают темный режим

4. **Адаптивные графики**
   - Квадратные на мобильных
   - Прямоугольные на десктопе
   - Легенда под графиком на маленьких экранах

5. **Умная таблица транзакций**
   - Горизонтальный скролл для сохранения данных
   - Скрытые колонки на малых экранах
   - Кнопка удаления при hover/long press

## ⚡ Быстрая настройка

### Включение тёмной темы вручную:

```javascript
// Добавьте в index.html перед закрывающим </body>:
<script>
  // Принудительно включить тёмную тему
  document.documentElement.classList.add('dark');
</script>
```

### Отключение тёмной темы:

```javascript
document.documentElement.classList.remove('dark');
```

## 🐛 Частые проблемы и решения

### Проблема: "График не отображается"
**Решение:** Проверьте что данные переданы корректно:
```javascript
// PortfolioChart expects: { accounts: [{name, balance}] }
<PortfolioChart :accounts="accounts"/>
```

### Проблема: "Тёмная тема не работает"
**Решение:** Убедитесь что класс `dark` добавлен к `<html>`:
```html
<html class="dark">...</html>
<!-- или -->
<script>document.documentElement.classList.add('dark');</script>
```

### Проблема: "Таблица слишком широкая"
**Решение:** Используйте горизонтальный скролл. Таблица имеет `overflow-x-auto`.

## 🚀 Быстрый старт для разработчиков

### Добавить новую вкладку:

1. Создайте компонент в `src/views/`
2. Добавьте в `router/router.js`
3. Добавьте в массив `menuItems` в `App.vue`
4. Обновите `SideBar.vue` (если нужно)

```javascript
// App.vue
const menuItems = [
  // ... существующие
  { name: 'New', icon: Icon, id: 'new' },
]
```

### Добавить адаптивный компонент:

Используйте Tailwind breakpoints:
```html
<div class="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3">
  <!-- Адаптивная сетка -->
</div>
```
