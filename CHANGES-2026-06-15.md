# 📝 Изменения для загрузки реальных счетов и категорий из БД

**Дата:** 2026-06-15  
**Проект:** FinanceApp Frontend + Backend

---

## 🎯 Цель изменений

Обеспечить, чтобы при создании транзакции в модальном окне выпадающие списки **"Счет"** и **"Категория"** заполнялись **реальными данными из базы данных**, а не моковыми (тестовыми) данными.

---

## 🔧 Что было изменено

### 1. Файл: `frontend/src/api/client.js`

#### Изменения:
- Добавлена обработка разных форматов ответа от API (`response.data.items` или `response.data`)
- Добавлено логирование всех запросов и ответов в консоль браузера для отладки
- Улучшена обработка ошибок при загрузке данных

```javascript
// Пример обработки ответа
const data = response.data || {}
return {
  ...response,
  data: {
    items: (data.items || data) || [],
    total: data.total || 0,
    totalPages: Math.ceil((data.total || 0) / (params?.limit || 20))
  }
}
```

### 2. Файл: `frontend/src/components/Modals/CreateTransactionModal.vue`

#### Изменения:
- Улучшена функция `loadAccounts()` для корректной обработки ответа от API
- Добавлена маппинг данных в единый формат для использования в форме
- Улучшена функция `loadCategories()` с обработкой вложенных категорий

```javascript
async function loadAccounts() {
  loadingAccounts.value = true
  try {
    const response = await accountApi.getAll()
    const data = response.data || {}
    // Обработка разных форматов ответа от API
    const items = (data.items || data) || []
    
    accounts.value = items.map(acc => ({
      id: acc.id,
      name: acc.name,
      type: acc.type || acc.account_type,
      currency: acc.currency,
      balance: acc.balance
    }))
  } catch (error) {
    console.error('Ошибка загрузки счетов:', error)
    accounts.value = []
  } finally {
    loadingAccounts.value = false
  }
}
```

## 🔍 Возможные проблемы

### Проблема: Пустые выпадающие списки

**Причина:** Нет счетов/категорий в базе данных

**Решение:**
```bash
cd /home/alex/Documents/finance/backend/app
poetry run python scripts/seed_sample_data.py
```

### Проблема: Ошибка 401 Unauthorized

**Причина:** Пользователь не авторизован или сессия истекла

**Решение:** Войдите в систему заново через Keycloak

### Проблема: Нет ответа от API

**Причины:**
- Бэкенд не запущен
- Неверный `VITE_API_BASE_URL` в `.env` файле

**Решение:**
```bash
# Проверьте .env файл
cat /home/alex/Documents/finance/frontend/.env

# Должно быть: VITE_API_BASE_URL=/api/v1 или http://localhost:8001/api/v1

# Запустите бэкенд
cd /home/alex/Documents/finance/backend/app
uvicorn main:app --reload
```
