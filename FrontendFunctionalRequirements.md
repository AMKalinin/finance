# Функциональные требования к фронтенд-приложению для системы управления личными финансами

## 1. Введение

### 1.1 Назначение документа
Данный документ описывает функциональные требования к веб-приложению для управления личными финансами, работающему в браузере на мобильных и десктопных устройствах. Приложение взаимодействует с REST API бэкенда на FastAPI.

### 1.2 Целевая аудитория
- Пользователи системы для отслеживания личных финансов
- Администраторы (при наличии подписки)

---

## 2. Общие требования

### 2.1 Платформа и устройства
- **Тип приложения**: Веб-приложение, работающее в браузере
- **Поддерживаемые браузеры**: Chrome, Firefox, Safari, Edge (последние 2 версии)
- **Мобильные устройства**: iOS 14+, Android 10+
- **Десктопные устройства**: Windows 10+, macOS 10.15+, Linux
- **Адаптивный дизайн**: Полная поддержка responsive design для всех размеров экранов

### 2.2 Технологии
- **Фреймворк**: Vue.js 3.x с Composition API
- **Стилизация**: Tailwind CSS 2.x + Custom CSS
- **Роутинг**: Vue Router 4.x (history mode)
- **HTTP клиент**: Axios
- **Графики**: Chart.js + vue-chartjs
- **Иконки**: Heroicons
- **Аутентификация**: Keycloak

### 2.3 Технические требования
- Поддержка HTTP/HTTPS
- CORS поддержка для взаимодействия с API
- Обработка ошибок и retry механизмы
- Кеширование данных (localStorage)
- Offline-first подход с синхронизацией при восстановлении связи

---

## 3. Функциональные требования

### 3.1 Авторизация и аутентификация

#### FR-AUTH-001: Вход в систему
- Пользователь должен иметь возможность войти в систему через Keycloak
- Поддержка Single Sign-On (SSO)
- Автоматическое обновление токенов (refresh tokens)
- Отображение индикатора времени жизни сессии

#### FR-AUTH-002: Выход из системы
- Пользователь должен иметь возможность выйти из системы
- Очистка локальных данных при выходе
- Перенаправление на страницу входа

#### FR-AUTH-003: Проверка авторизации
- Автоматическая проверка статуса аутентификации при загрузке приложения
- Защита маршрутов, требующих авторизации
- Перенаправление неавторизованных пользователей на страницу входа

### 3.2 Управление учетными записями (Accounts)

#### FR-ACC-001: Просмотр списка счетов
- Отображение всех активных счетов пользователя с пагинацией
- Показ баланса, названия, валюты и типа каждого счета
- Сортировка по названию или балансу (убыванию/возрастанию)
- Индикатор основного счета
- Возможность переключения между активными и архивированными счетами

#### FR-ACC-002: Создание нового счета
- Форма создания с полями:
  - Название (обязательно)
  - Тип счета (debit, savings, credit, loan_owed, loan_lent)
  - Валюта (RUB, USD, EUR и др.)
  - Начальный баланс
  - Описание (необязательно)
  - Процентная ставка (для кредитов/счетов с процентами)
  - Является ли счетом экстренного фонда
  - Количество знаков после запятой
  - Пометить как основной
- Валидация входных данных перед отправкой
- Отображение сообщений об ошибках

#### FR-ACC-003: Просмотр деталей счета
- Полная информация о выбранном счете
- История операций по счету (с возможностью фильтрации)
- Статистика доходов/расходов по счету

#### FR-ACC-004: Редактирование счетов
- Обновление имени счета
- Изменение описания
- Корректировка процентной ставки
- Настройка количества знаков после запятой
- Переключение статуса "основной" счета
- Пометка как счет экстренного фонда

#### FR-ACC-005: Управление балансом
- Обновление текущего баланса вручную
- Операции добавления/снятия средств
- История изменений баланса с фильтрацией по дате

#### FR-ACC-006: Архивация счетов
- Возможность архивировать неактивные счета
- Просмотр архивированных счетов в отдельном разделе
- Восстановление архивированного счета
- Удаление счета (с подтверждением)

### 3.3 Категории расходов и доходов

#### FR-CAT-001: Просмотр категорий
- Древовидная структура категорий с поддержкой уровней вложенности
- Разделение на категории расходов и доходов
- Отображение количества подкатегорий
- Иконки для каждой категории (опционально)

#### FR-CAT-002: Создание категорий
- Форма создания с полями:
  - Название категории (обязательно)
  - Тип (расход/доход)
  - Родительская категория (для вложенности)
  - Уровень иерархии
- Поддержка до 3 уровней вложенности
- Запрет на создание дубликатов

#### FR-CAT-003: Редактирование категорий
- Изменение названия категории
- Смена типа категории (расход/доход)
- Перемещение между уровнями иерархии
- Изменение родительской категории

#### FR-CAT-004: Удаление категорий
- Удаление категории с подтверждением
- Предупреждение о связанных транзакциях
- Возможность переназначить связанные транзакции на другую категорию

### 3.4 Управление транзакциями

#### FR-TRX-001: Просмотр транзакций
- Таблица/список всех транзакций с пагинацией
- Фильтрация по:
  - Дате (диапазон дат)
  - Типу операции (debit, adding, transfer)
  - Категории
  - Счетам (FROM/TO)
  - Статусу (pending, partially_paid, settled)
- Сортировка по дате, сумме, названию
- Поиск по описанию транзакции

#### FR-TRX-002: Создание транзакций
Форма создания с поддержкой различных типов операций:

**Дебетовая операция (debit):**
- Категория расхода/дохода (обязательно)
- Счет списания (FROM)
- Сумма списания (debitSize)
- Дата операции
- Описание
- Статус транзакции

**Перевод между счетами (transfer):**
- Откуда (FROM) - обязательно
- Куда (TO) - обязательно
- Сумма перевода
- Курс обмена (если разные валюты)
- Дата
- Описание

**Добавление средств (adding):**
- Цель (счет пополнения)
- Сумма добавления
- Дата
- Описание

#### FR-TRX-003: Распределение транзакций (Distributions)
- Возможность разделить сумму транзакции между несколькими пользователями/категориями
- Поддержка типов распределения:
  - Равные доли (equal)
  - Проценты (percentage)
  - Фиксированные суммы (amount)
- Редактирование распределений
- Пометка частей как оплаченных (settle)
- Отображение статуса оплаты для каждой части

#### FR-TRX-004: Позиции активов (Positions)
- Добавление позиций к транзакциям (акции, облигации и др.)
- Хранение количества акций/единиц
- Отслеживание изменения стоимости позиции
- Расчет прибыли/убытка

#### FR-TRX-005: Редактирование транзакций
- Изменение даты операции
- Корректировка суммы (debitSize)
- Обновление описания
- Изменение статуса транзакции
- Редактирование распределений и позиций

#### FR-TRX-006: Удаление транзакций
- Удаление с подтверждением
- Обработка связанных записей (распределения, позиции)
- Отмена удаления до подтверждения

### 3.5 Обзор и аналитика

#### FR-OVR-001: Дашборд概览
- Общий баланс всех счетов
- Итоги доходов/расходов за выбранный период
- Графики:
  - Расходы по категориям (pie/donut chart)
  - Динамика баланса во времени (line chart)
  - Доходы vs расходы (bar chart)
- Топ категорий расходов и доходов
- Статус счетов экстренного фонда

#### FR-OVR-002: Фильтры периода
- Выбор временного диапазона:
  - Быстрые фильтры (Этот месяц, Прошлый месяц, Этот год, Последний год)
  - Кастомный диапазон дат
  - Неделю/месяц/год с начала
- Агрегация данных по выбранным периодам

#### FR-OVR-003: Сравнение периодов
- Возможность сравнить текущий и предыдущий периоды
- Визуальное отображение изменений (процент, абсолютная разница)
- Выявление трендов расходов/доходов

### 3.6 Управление друзьями и совместные транзакции

#### FR-FRN-001: Добавление друзей
- Поиск пользователей по ID
- Отправка приглашения в друзья
- Отображение статуса запроса (отправлено, принято, отклонено)

#### FR-FRN-002: Управление друзьями
- Принятие/отклонение запросов в друзья
- Удаление друга из списка
- Просмотр списка друзей

#### FR-FRN-003: Совместные транзакции
- Создание транзакций с участием нескольких пользователей
- Распределение суммы между участниками
- Отслеживание статуса оплаты каждым участником
- Уведомления о необходимости оплаты

### 3.7 Профиль пользователя и подписка

#### FR-PFL-001: Информация о пользователе
- Отображение текущей информации профиля
- Тип подписки (free, premium)
- Дата истечения подписки (для платных тарифов)

#### FR-PFL-002: Управление подпиской
- Просмотр доступных планов подписки
- Переход на платный тариф
- Продление подписки
- История платежей

### 3.8 Поиск и фильтрация

#### FR-SCH-001: Глобальный поиск
- Поиск по транзакциям (описание, категория)
- Поиск по счетам
- Быстрый доступ к результатам через умную подсказку

#### FR-SCH-002: Продвинутые фильтры
- Сохранение настроенных фильтров
- Применение фильтров ко всем разделам приложения
- Сброс всех фильтров за один клик

### 3.9 Уведомления и обратная связь

#### FR-NOT-001: Визуальные уведомления
- Индикаторы загрузки при операциях с API
- Успешные/ошибочные сообщения о действиях
- Toast-сообщения для краткой обратной связи
- Модальные окна для критических действий (удаление)

#### FR-NOT-002: Ошибки сети
- Обработка ошибок соединения
- Автоматическое повторное подключение
- Индикация offline режима
- Буферизация операций при отсутствии связи

### 3.10 Настройки приложения

#### FR-SFT-001: Персонализация
- Выбор темы (светлая/темная)
- Предпочтительный формат даты (DD.MM.YYYY, MM/DD/YYYY, YYYY-MM-DD)
- Формат отображения чисел и валюты
- Язык интерфейса

#### FR-SFT-002: Экспорт данных
- Экспорт транзакций в CSV/Excel
- Экспорт отчетов в PDF
- Периодическая резервная копия (опционально)

## 4. Нефункциональные требования

### 4.1 Производительность
- **NFR-PERF-001**: Время отклика интерфейса < 200ms для всех операций без API
- **NFR-PERF-002**: Загрузка начального экрана < 3 секунды на 3G
- **NFR-PERF-003**: Поддержка до 10,000 транзакций с сохранением производительности
- **NFR-PERF-004**: Пагинация для всех списков с limit ≤ 1000 записей

### 4.2 Надежность и доступность
- **NFR-REL-001**: Доступность системы ≥ 99.5%
- **NFR-REL-002**: Автоматическое восстановление после сбоев сети
- **NFR-REL-003**: Обработка всех типов ошибок API с понятными сообщениями

### 4.3 Безопасность
- **NFR-SEC-001**: Все запросы к API через HTTPS
- **NFR-SEC-002**: Хранение токенов в secure storage (не localStorage)
- **NFR-SEC-003**: Защита от XSS и CSRF атак
- **NFR-SEC-004**: Валидация всех входных данных на клиенте

### 4.4 Доступность (Accessibility)
- **NFR-ACC-001**: Соответствие WCAG 2.1 Level AA
- **NFR-ACC-002**: Поддержка навигации с клавиатуры
- **NFR-ACC-003**: Альтернативные тексты для всех изображений и иконок
- **NFR-ACC-004**: Достаточный контраст текста (4.5:1 минимум)

### 4.5 Масштабируемость
- **NFR-SCA-001**: Возможность добавления новых типов счетов без изменений в коде
- **NFR-SCA-002**: Модульная архитектура компонентов
- **NFR-SCA-003**: Lazy loading для тяжелых компонентов

## 5. Интерфейс и пользовательский опыт

### 5.1 Навигация
- Боковая панель навигации на десктопе, bottom bar на мобильных устройствах
- Основные разделы: Обзор, Счета, Транзакции, Категории, Профиль
- Быстрый доступ к часто используемым функциям через меню "Быстрые действия"

### 5.2 Адаптивный интерфейс
| Элемент | Десктоп (>1024px) | Планшет (768-1024px) | Мобильный (<768px) |
|---------|-------------------|---------------------|--------------------|
| Навигация | Боковая панель | Боковая панель/табы | Bottom bar |
| Таблица транзакций | Полная таблица | Сворачиваемые колонки | Карточки |
| Модальные окна | Центрированные | На весь экран | На весь экран |
| Графики | Интерактивные с тултипами | Упрощенные | Вертикальные свайпы |

### 5.3 Визуальный стиль
- Современный минималистичный дизайн
- Цветовая схема: Primary (синий), Success (зеленый), Warning (желтый), Danger (красный)
- Анимации переходов между страницами и состояниями
- Индикаторы загрузки (skeleton screens, spinners)

## 6. API взаимодействия

### 6.1 Endpoints (соответствие бэкенду)

| Функция | Endpoint | Метод |
|---------|----------|-------|
| Получить все счета | `/api/v1/account/` | GET |
| Создать счет | `/api/v1/account/create` | POST |
| Получить счет по ID | `/api/v1/account/{id}` | GET |
| Обновить баланс | `/api/v1/account/{id}/balance` | PUT |
| Архивированные счета | `/api/v1/account/archived` | GET |
| Основные счета | `/api/v1/account/primary` | GET |
| Удалить счет | `/api/v1/account/{id}` | DELETE |
| Категории (все) | `/api/v1/category/` | GET |
| Расходы категории | `/api/v1/category/type/expenses` | GET |
| Доходы категории | `/api/v1/category/type/income` | GET |
| Создать категорию | `/api/v1/category/create` | POST |
| Удалить категорию | `/api/v1/category/{id}` | DELETE |
| Транзакции (все) | `/api/v1/transaction/all` | GET |
| Транзакции по периоду | `/api/v1/transaction/by_period` | GET |
| Создать транзакцию | `/api/v1/transaction/create` | POST |
| Распределение | `/api/v1/transaction/distribution` | POST/PATCH/DELETE |
| Оплата распределения | `/api/v1/transaction/distribution/settle` | PATCH |
| Позиции | `/api/v1/transaction/position` | POST/PATCH |
| Информация о пользователе | `/api/v1/user/info` | GET |
| Друзья | `/api/v1/user/friends` | GET |
