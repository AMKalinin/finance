# ⚡ Быстрый старт FinanceApp Frontend

## 🎯 Цель

Это Vue.js 3 приложение для управления личными финансами с:
- ✅ Аутентификацией через Keycloak
- ✅ Светлой и тёмной темами
- ✅ Поддержкой русского и английского языков
- ✅ Mock API для работы без бэкенда

## 🚀 Установка за 1 минуту

### Шаг 1: Установите зависимости (если ещё не установлены)

```bash
cd /home/alex/Documents/finance/frontend
npm install
```

### Шаг 2: Запустите сервер разработки

```bash
npm run dev
```

Сервер запустится на: **http://localhost:5173**

## 🎮 Использование приложения

### Демонстрационный режим (работает сразу)

Приложение запущено в демо-режиме с mock данными. Все функции доступны без бэкенда!

#### Навигация
- Используйте верхнее меню для перехода между страницами:
  - **Главная** 📊 - Дашборд и статистика
  - **Счета** 💰 - Управление банковскими счетами
  - **Транзакции** 📋 - История операций
  - **Категории** 📁 - Категории расходов/доходов
  - **Друзья** 👥 - Совместные финансы

#### Переключение тем
- Нажмите на иконку ☀️ или 🌙 в правом верхнем углу
- Или выберите режим "Авто" для автоматического переключения

#### Переключение языка
- Нажмите на кнопку RU/EN в правом верхнем углу
- Все тексты мгновенно переключатся между русским и английским

## 🔧 Работа с реальным бэкендом

Для работы с реальным FastAPI бэкэндом:

### 1. Настройте Keycloak сервер

```bash
docker run -d \
  --name keycloak \
  -p 8080:8080 \
  -e KEYCLOAK_ADMIN=admin \
  -e KEYCLOAK_ADMIN_PASSWORD=admin \
  quay.io/keycloak/keycloak:25.0 start-dev
```

### 2. Настройте realm в Keycloak

1. Зайдите в админку: http://localhost:8080/admin
2. Создайте realm `finance-app`
3. Создайте клиента `finance-frontend`
4. Настройте redirect URI: `http://localhost:5173/`

### 3. Обновите конфигурацию

Создайте файл `.env`:

```bash
cat > .env << 'EOF'
VITE_API_BASE_URL=http://localhost:8000/api/v1
EOF
```

### 4. Запустите FastAPI бэкенд (опционально)

```bash
cd /home/alex/Documents/finance/backend
uvicorn main:app --reload --port 8000
```

## 🐛 Решение проблем

### Приложение не запускается
1. Проверьте версию Node.js: `node -v` (нужно >= 18)
2. Удалите node_modules и установите заново
3. Очистите кэш: `npm cache clean --force`

### Не работают стили
1. Перезапустите dev сервер
2. Проверьте, что Tailwind CSS установлен
3. Очистите папку dist если собирали проект

### Ошибки Keycloak
- В демо-режиме приложение работает без реального Keycloak
- Для реальной аутентификации настройте Keycloak сервер по инструкции выше
