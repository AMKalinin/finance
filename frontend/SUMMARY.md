## 🎨 Реализованный функционал

### 1. **Авторизация через Keycloak** ✅
- Полная интеграция с Keycloak JS
- Поддержка SSO (Single Sign-On)
- Автоматическое обновление токенов
- Демо-режим для работы без реального Keycloak сервера

### 2. **Светлая и тёмная темы** ✅
- Переключение тем через кнопку в хедере
- Режим "Авто" для системных настроек
- Сохранение выбора в localStorage
- Плавные переходы между темами

### 3. **Мультиязычность (RU/EN)** ✅
- Полная локализация всех текстов
- Переключение языка через кнопку RU/EN
- Все переводы в `src/i18n/index.js`
- Поддержка добавления новых языков

### 4. **Инфраструктура для работы с API** ✅
- Axios клиент с интерцепторами
- Автоматическое добавление токенов авторизации
- Обработка ошибок сети
- Очередь запросов при offline режиме
- Mock данные для тестирования без бэкенда

### 5. **Роутинг и защита страниц** ✅
- Vue Router с history mode
- Защита маршрутов, требующих аутентификации
- Автоматическое перенаправление на страницу входа
- Lazy loading компонентов

## 📱 Доступные страницы

### 1. Главная (Dashboard) 📊
- Общий баланс всех счетов
- Статистика доходов и расходов
- Распределение расходов по категориям
- Последние транзакции
- Быстрые действия (создать транзакцию, добавить счёт)

### 2. Счета (Accounts) 💰
- Список всех счетов
- Создание новых счетов
- Архивация/восстановление
- Детали каждого счета: тип, валюта, баланс, процентная ставка

### 3. Транзакции (Transactions) 📋
- Список операций с пагинацией
- Фильтрация по типу и периоду
- Поиск транзакций
- Детальная информация о каждой операции

### 4. Категории (Categories) 📁
- Древовидная структура категорий
- Поддержка вложенности до 3 уровней
- Разделение на расходы, доходы, переводы
- Иконки для категорий

### 5. Друзья (Friends) 👥
- Запросы на добавление в друзья
- Список друзей с активностью
- Совместные транзакции
- Управление уведомлениями

## 🎓 Для разработчиков

### Добавление новой страницы
1. Создайте файл в `src/views/NewPageView.vue`
2. Добавьте маршрут в `src/router/index.js`:

```javascript
{
  path: '/new-page',
  name: 'NewPage',
  component: () => import('@/views/NewPageView.vue'),
}
```

### Изменение стилей
- Используйте Tailwind utility classes
- Для кастомных стилей добавьте в `src/assets/css/tailwind.css`

### Работа с API
- Реальные запросы: `src/api/client.js` (реализация)
- Mock данные: `src/api/client.js` (mockData объект)

## 🐛 Решение проблем

| Проблема | Решение |
|----------|---------|
| Приложение не запускается | Проверьте Node.js >= 18, выполните `rm -rf node_modules && npm install` |
| Не работают стили | Перезапустите dev сервер, проверьте Tailwind CSS |
| Ошибки Keycloak | В демо-режиме приложение работает без реального Keycloak |
| API запросы не работают | Проверьте VITE_API_BASE_URL в .env файле |
