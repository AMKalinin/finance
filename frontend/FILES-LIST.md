## 💾 Исходный код - State management (Pinia)

### src/stores/languageStore.js (686 символов)
Управление языком:
- currentLocale (ref) - текущий язык
- setLanguage(lang) - установка языка
- toggleLanguage() - переключение языка

**Назначение**: Переключение между RU/EN

### src/stores/themeStore.js (1,357 символов)
Управление темой:
- themeMode (ref) - режим темы (light/dark/auto)
- isDark (computed) - вычисленное свойство
- setThemeMode(mode) - установка режима
- toggleTheme() - переключение темы
- updateSystemTheme() - адаптация к системным настройкам

**Назначение**: Переключение светлой/тёмной тем

### src/stores/userStore.js (939 символов)
Информация о пользователе:
- userInfo (ref) - данные пользователя
- friends (ref) - список друзей
- isLoading (ref) - статус загрузки
- fetchUserInfo() - загрузка информации
- fetchFriends() - загрузка друзей

**Назначение**: Управление данными пользователя
