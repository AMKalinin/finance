# Улучшения производительности Finance Backend

## 📊 Добавлена индексация базы данных (11 мая 2025)

### Обзор изменений

Добавлены индексы ко всем основным таблицам для оптимизации частых запросов:

- **Account** - 4 индекса
- **Category** - 3 индекса  
- **Transaction** - 3 индекса (самые важные!)
- **User** - 1 индекс
- **Friends** - 2 индекса
- **Position/Position_user** - 3 индекса
- **Transaction_distribution_user** - 2 индекса

### Ожидаемое улучшение производительности

| Тип запроса | Ускорение |
|-------------|-----------|
| Поиск транзакций по дате | ~10x-100x |
| Фильтрация счетов пользователя | ~5x-50x |
| Проверка друзей | ~3x-20x |

### Как проверить

```bash
# Просмотр индексов
poetry run python scripts/check_indexes.py

# Применение новых индексов
poetry run python scripts/create_indexes.py
```
