# Скрипты для управления базой данных Finance Backend

## Описание

Этот каталог содержит вспомогательные скрипты для работы с базой данных.

---

## 📋 check_indexes.py

Проверяет наличие и правильность создания индексов в базе данных.

### Запуск

```bash
# Через poetry (рекомендуется)
poetry run python scripts/check_indexes.py

# Или напрямую
python3 scripts/check_indexes.py
```

### Что показывает:

1. **Индексы** - все существующие индексы для каждой таблицы
2. **Первичные ключи** - основные идентификаторы таблиц
3. **Внешние ключи** - связи между таблицами
4. **Эффективность запросов** - план выполнения популярных SQL-запросов

### Пример вывода:

```
======================================================================
📊 ТАБЛИЦА: ACCOUNT
======================================================================

📌 ИНДЕКСЫ:
   ✅ ix_account_user_is_deleted             on columns: user_id, is_deleted
   ✅ ix_account_user_archived               on columns: user_id, is_archived
   🔒 pk_account                              on columns: id

🔑 ПЕРВИЧНЫЕ КЛЮЧИ:
   🔐 id

🔗 ВНЕШНИЕ КЛЮЧИ:
   ➡️ user_id → user.id
```

## 💡 Рекомендации

1. **Регулярно проверяйте индексы** после изменений в схемах БД
2. **Используйте EXPLAIN QUERY PLAN** для анализа медленных запросов
3. **Удаляйте неиспользуемые индексы** - они замедляют INSERT/UPDATE операции
