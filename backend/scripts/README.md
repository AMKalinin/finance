# Скрипты для управления базой данных Finance Backend

## Описание

Этот каталог содержит вспомогочные скрипты для работы с базой данных.

---

## 📋 check_indexes.py

Проверяет наличие и правильность создания индексов в базе данных.

### Запуск

```bash
# Через poetry (рекомендуется)
poetry run python scripts/check_indexes.py

# Или напрямую
python3 scripts/check_indexes.py
```

### Что показывает:

1. **Индексы** - все существующие индексы для каждой таблицы
2. **Первичные ключи** - основные идентификаторы таблиц
3. **Внешние ключи** - связи между таблицами
4. **Эффективность запросов** - план выполнения популярных SQL-запросов

---

## 🔧 create_indexes.py

Принудительно создаёт все необходимые индексы в базе данных.

### Запуск

```bash
poetry run python scripts/create_indexes.py
```

Используется когда таблицы уже существуют и нужно добавить новые индексы.

---

## 🗑️ clean_db.py

Полная очистка базы данных (удаляет все данные, сохраняет структуру).

### Запуск

```bash
# Очистить данные (сохраняет структуру)
poetry run python scripts/clean_db.py
# Выберите: 1 - очистка данных

# Удалить все таблицы
poetry run python scripts/clean_db.py
# Выберите: 2 - удаление таблиц
```

⚠️ **ВНИМАНИЕ**: Это действие необратимо!

---

## 🔍 check_integrity.py

Проверяет целостность данных в базе:
- Дубликаты записей
- Целостность балансов счетов
- Внешние связи (сиротские записи)

### Запуск

```bash
poetry run python scripts/check_integrity.py
```

---

## 🌱 seed_sample_data.py

Заполняет базу данных тестовыми данными (счета и категории).

**Используйте этот скрипт после создания БД, чтобы иметь данные для работы в приложении.**

### Запуск

```bash
# Через poetry (рекомендуется)
poetry run python scripts/seed_sample_data.py

# Или через bash-скрипт
./scripts/init_sample_data.sh
```

### Что создаёт:

1. **4 тестовых счета:**
   - Сбербанк (RUB, баланс 50,000 ₽)
   - Тинькофф (RUB, баланс 12,345.67 ₽)
   - American Express (USD, баланс $2,500)
   - Кредитная карта (RUB, долг -15,000 ₽)

2. **Категории расходов:**
   - Еда → Еда на дом, Еда на вынос, Продукты
   - Транспорт → Заправка
   - Жилье
   - Здоровье
   - Образование

3. **Категории доходов:**
   - Зарплата
   - Инвестиции
   - Подарки

## 💡 Рекомендации

1. **Регулярно проверяйте индексы** после изменений в схемах БД
2. **Используйте check_integrity.py** перед продакшен-релизами
3. **Используйте EXPLAIN QUERY PLAN** для анализа медленных запросов
4. **Удаляйте неиспользуемые индексы** - они замедляют INSERT/UPDATE операции
